# 新闻资讯插件 v1.1.2 更新说明

## 版本类型

向后兼容的修订版本。

## 主要内容

- 补充 v1.0.0、v1.1.0、v1.1.1 和当前版本的独立更新说明；
- 明确数据库变化、升级步骤、兼容性和回滚方式；
- 适配宿主对 `docs/updates/v{version}.md` 的发行校验要求。

## 数据库变化

无新增迁移，继续使用 v1.1.0 数据库结构。

## 升级操作

停用插件后使用 `plugin upgrade --apply-database`，完成后重新构建并重启管理端前端、管理端 API 和用户端 API。

## 兼容性与回滚

业务接口、页面和数据库结构均保持兼容。回滚到 v1.1.1 不需要变更数据库，但必须同步恢复插件源码和版本记录。
