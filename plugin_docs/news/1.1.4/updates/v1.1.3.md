# 新闻资讯插件 v1.1.3 更新说明

## 版本类型

向后兼容的修订版本。

## 主要内容

- API 文档改为 `docs/api/v{version}.md` 按版本保存；
- 数据库说明改为 `docs/database/v{version}.md` 按版本保存；
- 顶层文档保留为当前版本阅读入口。

## 数据库变化

无新增迁移，继续使用 v1.1.0 数据库结构。

## 升级操作

停用插件后使用 `plugin upgrade --apply-database`，完成后重新构建并重启相关服务。

## 兼容性与回滚

业务接口和数据库结构均未变化。回滚到 v1.1.2 不需要回滚数据库。
