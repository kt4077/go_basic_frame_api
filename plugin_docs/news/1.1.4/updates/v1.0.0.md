# 新闻资讯插件 v1.0.0 更新说明

## 版本类型

首次发布。

## 主要内容

- 新增新闻分类管理；
- 新增文章草稿、发布、下线和软删除；
- 新增文章封面上传与动态地址补全；
- 新增用户端分类、文章列表和详情接口；
- 新增插件菜单和首版数据库迁移。

## 数据库变化

首次创建 `plg_news_category` 和 `plg_news_article`，安装时必须使用 `--apply-database`。

## 升级操作

首次安装使用 `plugin install`。安装完成后构建管理端和两个 API 服务，启用插件并重启服务。

## 兼容性与回滚

要求 Go Basic Frame 核心版本 `0.0.2`。回滚前应先停用插件；业务数据默认保留。
