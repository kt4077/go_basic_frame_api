# 新闻资讯插件 v1.1.4 更新说明

## 版本类型

向后兼容的修订版本。

## 主要内容

- 文章正文改为复用宿主 `RichTextEditor` 通用组件；
- WangEditor 工具栏、编辑区、下拉面板、输入弹层、代码块和引用适配管理端亮色、暗色主题；
- 图片上传和编辑器销毁生命周期由宿主组件统一处理，方便其他插件直接复用。
- 文章列表封面移除背景和外框，直接完整展示原图；无封面时保留独立空状态提示。

## 数据库变化

无新增迁移，继续使用 v1.1.0 数据库结构。

## API变化

无接口、请求字段或响应字段变化。

## 升级操作

1. 确认核心管理端已经提供 `src/components/RichTextEditor.vue`；
2. 停用插件后执行 `plugin upgrade --apply-database`；
3. 重新安装管理端依赖并完成生产构建；
4. 重新启动管理端 API 与用户端 API，再启用插件。

## 兼容性与回滚

业务接口和数据库结构均未变化。回滚到 v1.1.3 不需要回滚数据库，但必须同步恢复管理端插件源码并重新构建。
