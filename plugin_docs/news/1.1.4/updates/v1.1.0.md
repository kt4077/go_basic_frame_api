# 新闻资讯插件 v1.1.0 更新说明

## 版本类型

向后兼容的功能更新。

## 主要内容

- 文章新增和修改调整为独立页面；
- 文章正文接入 WangEditor 富文本编辑器；
- 新增文章启用状态和虚拟阅读数量；
- 用户端只返回已发布且启用的文章。

## 数据库变化

执行 `database/migrations/v1.1.0.sql`，为 `plg_news_article` 增加 `enable_status` 和 `virtual_view_count`。

## 升级操作

宿主管理端需要安装 `@wangeditor/editor` 和 `@wangeditor/editor-for-vue@next`。停用插件后使用 `plugin upgrade --apply-database`，随后重新构建并重启前后端服务。

## 兼容性与回滚

新增字段均提供默认值，旧文章自动保持启用且虚拟阅读数为零。回滚代码前应确认旧版本不会读取新增字段。
