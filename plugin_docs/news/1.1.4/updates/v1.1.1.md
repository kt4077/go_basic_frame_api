# 新闻资讯插件 v1.1.1 更新说明

## 版本类型

向后兼容的修订版本。

## 主要内容

- 文章列表将封面、标题、标识和摘要拆分为独立列；
- 封面完整展示并支持点击预览；
- 分别展示真实阅读、虚拟阅读和总阅读；
- 新增分类和文章时自动生成可编辑标识，创建后禁止修改；
- 调整文章编辑页布局，正文编辑区位于右侧。

## 数据库变化

无新增迁移，继续使用 v1.1.0 数据库结构。

## 升级操作

停用插件后使用 `plugin upgrade --apply-database`。安装器会更新源码和插件版本记录；完成后重新构建并重启管理端前端、管理端 API 和用户端 API。

## 兼容性与回滚

接口保持向后兼容。回滚到 v1.1.0 不需要回滚数据库，但必须同步恢复前后端插件源码并重新构建。
